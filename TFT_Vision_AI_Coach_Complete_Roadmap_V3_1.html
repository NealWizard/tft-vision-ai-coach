LLM / AI Provider 可替换架构

硬约束：业务代码不得直接绑定 ChatGPT/OpenAI、DeepSeek 或任何具体厂商 SDK。所有模型能力统一通过 Provider SPI → Model Registry → Model Router 使用。更换模型只改变 Provider 实现和配置，不改 Economy、Shop、Composition、Replay 等业务 Agent。

任务清单

V3.1 基于 V3 的全量任务模型补充技术细则，不重新增加业务能力、不改变 Phase/Capability 唯一性。已校验：Task ID 唯一、依赖完整、Phase 有序、P1 仅一个 Knowledge Agent v1。

关键设计门禁

  • P1 只有一个 P1-AGENT-Knowledge-001，它本身就是 Structured Tools + RAG + Cloud LLM 的组合能力。
  • P3 的 Decision Agents 才进入 Decision RAG 和 Cloud LLM 决策综合，数学规则仍由 Tool 提供。
  • P4 才建立 Personal RAG 和 Personal Coach；玩家历史不能覆盖通用事实。
  • P5 才建立 Model Router / RAG Router，确保简单问题可以 0-LLM。
  • P6 Live 默认关闭；未获明确政策/产品许可则不继续 Live。
